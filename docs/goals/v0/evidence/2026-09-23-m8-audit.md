## 本次补的实现与测试

- **作品页的 Context Preview 与 Diff（实现）**：原来 Preview 与 Diff 只在 Playground 里对示例作品运行，作品页没有入口，不满足“作者发布之后 Preview 能解释每个 fragment”。新增 `/c/$ns/$name/preview` 与 `/c/$ns/$name/diff` 两个页面，作品页加上“Preview”与“Compare versions”入口；Preview 面板抽成 `PreviewPanel`，Playground 与作品页共用。mature 版本同样先遮挡。
- **编辑器的渐进式展示（修复）**：“More options”原来只要草稿里有任何 fragment 就默认展开，而第一层的正文本身就是一个 fragment，所以任何能保存的草稿打开时都是展开的。改为只有第一层之外还有 fragment 或依赖时才默认展开。
- **新增 Playwright**：web `registry-pages.spec.ts`（4）、`editor.spec.ts`（5）、`preview-diff.spec.ts`（3）；admin `moderation-extra.spec.ts`（2）；按需的截图 `m8-screenshots.spec.ts`（`M8_SCREENSHOTS=1`）。

## 遗留

- Preview 的解释是否清楚，需要用户按上面的问题审阅截图后给出结论（M8-3）。
- 作品页的 Diff 不传依赖锁定的 label，依赖变化显示 release ID（IR 只保存 lock 的 digest）；如果需要显示版本号，需要服务端在 Release 详情里返回锁定的依赖列表。
- 这些页面在 staging 上的真人走查属于端到端验收（E2E-1、E2E-3），不在本次审计范围内。
