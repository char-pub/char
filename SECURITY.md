# Security Policy

char.pub is an open registry. This repository is public; security never depends on source code being secret.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

- Use GitHub private vulnerability reporting: **Security → Report a vulnerability** on this repository.
- Include affected component (core / server / web / admin / cli / action), reproduction steps, and impact.

We aim to acknowledge reports within 3 business days and to provide a remediation plan within 14 days.

We follow a 90-day coordinated disclosure policy: please give us 90 days from your report before publishing details, unless we agree on a different timeline together.

## Scope

In scope: code in this repository, `*.char.pub` services, the `char-pub/publish` GitHub Action, and published `@char-pub/*` npm packages.

Out of scope: denial-of-service volume tests, social engineering, reports from automated scanners without a demonstrated impact.

## Illegal content

To report child sexual abuse material or other illegal content hosted on char.pub, use the in-product report function or the contact listed on https://char.pub. Do not send such material to us.
