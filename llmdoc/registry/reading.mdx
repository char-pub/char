# Release 读取与发现

读取层从持久 Release 状态构造对外表示。公开和私有资源的可见性由服务端身份与授权决定；私有内容不能通过搜索结果、错误差异或资产 URL 被猜出。tombstoned 内容不得继续分发，yanked 保留明确状态与警告语义，不等于删除。

搜索同时处理常见词与短中文查询，使用数据库索引策略而不是单靠前端筛选。内容分级必须在服务端查询与返回边界实施，页面上的筛选参数只改善展示，不能承担权限。公开资产通过受控 CDN 路径提供，私有资产使用短期签名 URL；URL 的生成和跳转不能泄露原始私有存储键。

搜索和个人作品列表返回受控头像入口。草稿头像签名除草稿读取权限外，还要求当前用户本人拥有对应的 ready 上传，并检查 digest 黑名单；持有或粘贴 digest 不能证明私有对象读取权，因此另一维护者上传的未发布头像不会仅凭成员身份开放。Release 头像从已解析 IR 选择本作 mirrored avatar，再按 Release 可见性跳转公共 URL 或私有签名，tombstone 与黑名单仍阻止分发。

Release 的来源和发布者摘要只挑选公开契约需要的字段，不直接返回原始 OIDC 声明或内部身份载荷。

修改发布状态或资产存储时，核对读取、搜索和缓存是否仍遵守同一可见性；下架的事务状态与公网副本实际清除之间还存在异步清理边界。
