# 读取、分发与发现

读取按持久状态与中央授权判断；知道精确 Release ID、ref 或 digest 不是权限。精确 ID 路由与 label 路由共用读取规则，私有不可见对象统一 404。tombstone 不再分发，yanked 保留状态语义。列表必须先授权再分页，不能让未授权行挤占结果或泄露隐藏数量。

Artifact CAS 命中以存储摘要为字节权威，并经 PublishedArtifact guard 核根 Release/semantic 与所有嵌套来源；不得将 draft/local origin 混进发布接口。需要重建时只使用该 Release 的固定 snapshot、默认策略和依赖；row/snapshot default pin 不一致拒绝，不能用当前环境默认补旧版。内容与策略产物严格分型，策略不伪造 IR。

展示评级、警告、许可、署名与能力使用当前精确 Artifact 的聚合 meta；IR 根元数据可能遗漏策略或历史来源。加载、失败与 legacy 不能伪装成已验证聚合结论。公开分发与私有短期签名不同，后者不暴露存储内部键；已签字节受 TTL 限制，撤权阻止后续获取而不宣称撤回已下载内容。

草稿头像与 Source 正文同时要求作品读取权和实际资产来源授权。作品 grant 可让已确认协作者使用该作品资料，不能由 namespace 维护者身份推导其它私有字节权利。Source endpoint 只收 full Catalog Source ID，先授权根 Release/dbld，再绑定其实际 Artifact与asset/digest读取，no-store；不提供通用 digest 下载或外链抓取。

搜索使用数据库索引处理词与短中文，服务端承担分级和可见性，客户端筛选仅用于呈现。Favorites 保存作品身份，展示时重新按当前可读作品/Release过滤；收藏不是草稿、私有内容或固定版本授权。

CCv3 导出先授权角色和精确策略，缓存键结构化绑定 Release ID、可见桶、semantic/lock、compiler、locale 与可选精确 preset。同Revision的两个Release也不能共享可错归属的身份缓存。所有路径使用同一键，命中仍重验权限；未完成202，card/loss分别交付并明确有损。

下架事务禁止新访问与异步清除分发副本是不同状态；修改存储、缓存或源身份时，必须核对精确路由、搜索、头像、Source、导出都遵守同一边界。
