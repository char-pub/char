# 本地作者与 CLI

char.yaml及include文件先加载为Creation并canonicalize；include不能越项目边界，check --fix的稳定标识修改应幂等。loadLocalCreation提供真实作品身份和semantic digest，不需要先伪造Release或默认策略完成Artifact构建。实际build/preview/test另要求完整精确依赖和有效策略。

离线构建使用local-build origin，输入摘要固定规范化、去重后的依赖和配置；不能伪造Registry dbld或把local结果作为依赖pin。依赖仍只接受ExactRef；内容缺assembly/default-policy明确失败。产物按content/preset/module分型，不为策略生成空IR。

预览经过公开prepareContext与startSession。新Session显式选择多开局；有完整snapshot则不重新初始化。locale优先显式参数，再实际锁定profile，最后作品默认；Source以主动提供的原bytes校验和按需提取。Session是本地合成输入，不复制进静态assembly。实现/tokenizer版本错误不回退成估算。

作者fixture通过同一SDK执行；保留session/source_texts精确字符串，root:self避免循环摘要，不能把错误依赖/配置包装成预期组装错误。观察到的新输出须明确审阅写入expected，CLI不调用模型。

远端发布按最新draft版本If-Match写入，再取得Revision，以同一幂等键请求发布并观察worker结果。409保留本地输入，不盲目重写；未知结果先查询或重试原请求，不能认为接收即active。本地校验从不替代服务器的动态依赖授权、许可、资产和黑名单检查。
