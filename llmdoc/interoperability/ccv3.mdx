# CCv3 互操作边界

导入器把外部卡片转换为 Creation 候选，而不是赋予其发布可信度。卡片的 `system_prompt`、`post_history_instructions` 属运行策略，不进入 Creative Truth；默认原值只保留在私有原件及 Import Report 中；只有明确选择策略转换才可生成独立 Preset，不能自动注入角色正文。权利、评级、许可等不能从卡片自动确证，导入结果使用待确认值并要求作者在发布前明确确认。Lorebook 来源 ID 目前保守标为不稳定，避免把可能变化的条目标识当成可持久引用。

PNG 和 CHARX 是不可信容器。解析须限制大小、校验格式和 CRC，防止路径穿越及资源耗尽；抽取的资产仍需走上传净化与状态流程。单个容器通过解析不意味着其中图片或权利字段已获准公开。

导出面向有损的外部消费者，必须生成 Loss Report，说明完整 Artifact 中外部格式无法表示的内容、状态和策略。导出消费完整产物与实际 locale，不能只把 IR 子树当作所有可分发语义。IR 的 `meta.import_omissions` 从 Creation provenance 中的 omitted policy fields 推导，两个字段位于不同层级，不能互相复制成同一路径。

显式策略导入保留原卡作者署名，生成独立身份、已确认权利元数据的 Preset；文本仍按字面处理。导出使用完整性已验证的产物及实际精确策略，启用的 main/after-history 块分别进入对应卡字段，禁用块不导出。布局、能力、区域预算、模块来源及宏语义差异进入实际 Loss Report，不能宣称无损；完整署名、许可和最高评级需随聚合策略元数据传入，缺失时必须报告未验证部分。Registry 的 card/loss 分发与授权由读取层持有。

Story的可选分支、三值条件、knowing、cast独立实例、资料分组/Source/章节、selectable、about与高级语义并不能全部落入CCv3；实际损失必须逐项报告，不因保留了部分文本就称无损。原素材/策略宏仍是字面数据，不执行外部代码。
