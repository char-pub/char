# 规范化、身份与摘要

Creation 是可编辑定义，Revision 是不可变内容快照，Release 是已发布身份；label 是同一作品下的人类标记，不执行 SemVer 范围解析。依赖 ExactRef 只能指向发布版。构建根严格二选一携带 release 或 origin；origin 再区分 Registry 的 draft-build（build/revision/expiry）与离线 local-build（input_digest）。根、IR 节点/片段/资产、策略来源与 Trace 需一致保留身份，不允许混合身份或用假 Release 表示草稿。

普通作者正文按 NFC、统一换行、行尾空白等规则规范化，严格 schema 拒绝未知字段和非纯 JSON；JCS 与 SHA-256 产生稳定摘要。fragment digest 排除自身字段，作品 manifest 用有声明顺序的 fragment identity/digest 表示内容；对象键顺序不影响身份，有语义的数组顺序不能排序。

精确域是显式结构契约：assembly_tests 中完整 session 与 source_texts 保留原字符串和 record keys，不做 prose 归一化；仍要求纯 JSON 与有限数。该例外由实际结构上下文定位，不是可伪造的路径字符串匹配。snapshot、merge/configurationDigest、重复输入判等与实际编译都必须保留同一契约。公开 normalizeValue 仍是通用正文规范化，不可随意用于 runtime 输入。

digestExactJSON 用于原字符串敏感的运行输入、目录/Plan 绑定与审阅回执；JSON 键序等价不等于 CRLF/NFD/尾空白等价。local-build 摘要包含 domain、实现版本、完整规范化依赖集合与配置；创建 receipt 和执行构建共同使用规范化、去重集合，同一发布身份的真实内容冲突必须拒绝。

semantic_digest 标识作者定义；artifact digest 标识完整构建字节；lock digest 标识依赖集合；运行输入摘要标识当轮上下文。签名、缓存、来源和选择重放必须使用对应层级，不能互换。源地址改名也不能替换历史 Release 内的原始 ref。

Preset/Module 与 Creative Truth 分开，策略块是字面文本而非可执行宏。Preset 定义块/导入与其 placement 实例分开，实例有独立身份、排序与覆盖语义；规范默认值归一化必须保留显式 false。严格 1-draft 迁移不承诺旧 v0 字节不变。

Published 产物校验覆盖所有可分发来源，包含嵌套 block origin、assembly preset 与 default_policy 两条分支；当前执行只选一条策略不构成跳过备用来源校验的理由。
