# 删除请求、下架与证据

自助删除请求（账号删除或作品移除）只进入法律请求队列，不直接执行删除。入口要求浏览器登录会话、原因和明确确认，个人 Token 不可代办；作品请求还须通过 creation.edit 授权。原因和请求者详情加密保存，明文 owner_user_id 仅作为本人查询与去重索引，审计不复制原因。缺少法律加密密钥时拒绝受理；限流和事务内同主体同对象待处理请求去重约束重复提交。

提交回执与本人状态列表表示受理进度，受权管理端解密展示身份、请求类型与原因供审阅。实际下架仍需独立管理处置及影响核对，不能从受理成功推断已删除。

下架先预览依赖和引用影响，再由有权管理人员触发。事务内更新 Release 状态、内容 digest 黑名单、必要的级联对象、审计事件和待处理任务；这样新的读取与重新发布会立即被拒绝。但数据库提交不等于公网副本已消失。worker 还须删除公开与私有分发对象、核验 HEAD 结果并清除 CDN 缓存；失败持续重试并保持可观察状态，直到分发清除完成。

CSAM 或法律证据独立保存在受限证据存储，不因公共副本删除而一起消失。证据下载受角色、理由和 case 约束。审计链按追加和哈希校验设计，业务写入与审计同事务，应用数据库角色不得任意修改历史记录；迁移和权限设置是此保证的一部分。

处置时区分“已禁止新访问”“公共副本清除已核验”“证据依法保留”三个状态。不能把任务入队或单次 CDN 请求成功当作完成信号。
