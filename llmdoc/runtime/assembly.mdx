# 逐轮 Context 组装

Assembler 消费不可变 Context IR 和本轮 Session 输入，完成 late binding、activation、visibility 过滤、预算和最终渲染。它不重新解释 Creation、选择内容依赖版本或改变 Creative Truth。Session 提供可变状态；visibility 与激活先于预算，Preset 不能重新加入被排除片段。narrator 对 private 内容的知情者标注不构成模型内隔离，semantic 激活不可用也不能悄悄当作精确匹配。

Preset 是独立的 Policy 输入。调用方先把完整作品快照、精确 Release 和期望摘要交给纯计算 `resolvePreset`，经严格校验、规范化与完整 semantic digest 比对后取得 `ResolvedPreset`。数据读取、可见性、发布状态及 Release 到快照的可信映射仍归调用方或 Registry；摘要不证明授权或作者真实性。Assembler 只校验解析结果结构，不能从 policy 重算完整作品摘要，也不能替代上游完整性校验。

显式 Preset 按完整布局组织区域；main 块在所有区域之前，after-history 块在所有区域之后，历史内部顺序和角色保持不变。Runtime 必须明确支持所需 system 能力；仅支持单 system 消息时只能合并相邻消息，不能跨历史挪动内容，不兼容时显式失败。无 Preset 时保留既有默认布局、预算顺序与能力降级，不能把显式策略的严格保证外推到默认路径。

显式策略先扣历史、Session 与启用块等固定成本，再预留全部可见 pinned。固定内容或 pinned 超全局预算、pinned 超区域上限均失败；其余按 normal、opportunistic、布局及区域内 IR 顺序整条纳入或跳过。区域上限只约束 Creative 片段本身，不是预留份额，不重复扣 Session 或策略成本。

全局成本取逐来源文本计数总和与最终各消息文本计数总和的较大值，固定内容、全部 pinned 和每次加入普通候选后都要满足预算。这样覆盖合并分隔符、示例标题与分词拼接边界，且不利用合并偶然减少的 token 扩容。最终文本比来源多出的正差额记为 `assembly:formatting`，使 Trace 总数等于 included 成本之和；不含供应商消息封装或图片计费，Runtime 仍需预留。默认路径保留原逐来源口径。

Trace 分别记录内容 IR 锁、实际 Preset 身份、Assembler 与布局版本，并保留片段选择原因和策略块来源；审计 entry 顺序不等于最终消息顺序。推荐 Preset 不意味着已选用或已锁版本。复现组装还须固定 Session、Profile、Assembler 和 tokenizer，不保证模型生成相同文本。

`diffPresets` 按稳定块 ID 和共同块相对顺序比较规范化策略，与 Creative Context Diff 分开；默认值等价形式不产生差异。它不比较完整作品元数据，也不重新验证快照摘要；调用方仍需先走独立解析器，不能把无策略差异解释为作品未变。
