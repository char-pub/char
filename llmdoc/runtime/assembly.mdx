# 上下文准备、策略与消息

公开 assemble 与 prepareContext 使用完整 CreationArtifact、RuntimeProfile 和 Turn；调用方不能绕过准备步骤把任意 IR 交给旧渲染器。配置解析先确定实际策略：省略 preset 时使用锁定 assembly（若有），显式 null 请求 artifact.default_policy；内容始终必须有有效策略。推荐 Preset 不等于已锁定。

策略解析先用完整作品快照、精确身份与预期semantic digest校验，不能从已解析policy子树反证原作品摘要；数据来源和权限仍由Registry或调用者负责。Preset只导入Module，模块可继续导入模块；局部blocks/imports索引按placement路径逐层查找，不枚举菱形全部路径。cycle/版本冲突/实例ID碰撞失败，alias不能跳过来源校验。

viewOf 先按当前场次、人物、知情关系和 visibility 投影，再供目录/选择使用。每个 late slot 独立绑定；per-agent 的发言对象必须是实际参与者。narrator 的知情标注不提供同一模型内的秘密隔离。离场人物的 late description 不能通过其它渲染阶段重新进入消息；公开 outward 与私人描述分开。

projectPlayerView 独立于 narrator 模型上下文，从受控人物自己的 per-agent 视角给出当前场次、在场 NPC 的 outward 画像、显式 knowing 且当前可见的知识、可用 Choice 与已达成公开里程碑；不暴露 NPC 私目标、原始变量/条件、判定提示或未来人物，也不加载 Source 或把可检索当作已知。旧作品保守使用隐式 user，在场状态未知、known 为空。显式玩家控制还进入必需且计预算的 session:player-control 上下文，不能被可选选择或预算截断移除。

渐进暴露先给可见定义的 description 与元数据，展开 group/source/section 受深度、目录与请求预算限制。about、perspective、activation_hint 同样进入 DTO/预算/hash，不能作为正文或隐藏身份旁路。目录可发现不等于被选中；required/direct 与 selector 的可选候选分别处理，选择失败的 skip/unknown 不得自动扩大读取范围。目录正文估算与渲染共用同一 fragment 语言变体选择：BCP 47 lookup 逐级截短、不区分大小写，默认正文优先级与未命中回退一致，不能拿默认文本成本估算已选中的译文。

SelectionPlan 绑定精确 artifact/lock、当前输入、可见目录、发现过程与预算。history、focus、overlay 等原字符串变化使旧 Plan 无效，键序等价 JSON 可重放。Plan 不能通过重复ID、越界引用、伪身份或客户端超额预算绕过策略。提供方只提出选择，真正准入与排序仍由确定性 SDK 校验。selected 是最终正文清单，同一 ref 的最后显式 reject 不得与入选矛盾；缺少终局决定的旧 Plan、尚未入选的 select 和增量/skip 记录仍可成立，不能把决策日志误当正文清单。

sourceRequests 列出实际所需资料；调用者只加载这些原 UTF-8 bytes 并验证 digest，Core 再按统一 BOM/换行/Markdown 锚点语义取正文。Locator、origin、source、data、pin、about 不是正文 include 展开入口；不抓外链、不把未选章节自动给模型。固定策略块、历史、required/direct 内容和选中内容都受最终消息成本约束；溢出不能静默截断必需内容。

选择与预算顺序不等于最终消息布局。Preset placement 实例、region/layout、历史边界和 Style 内外层顺序决定渲染；replace 遵循实例作用域。最终文本与分隔格式成本纳入预算，Trace 解释实际来源/placement、准入、计数与失败；Trace 行顺序不是 messages 顺序。模型供应商封装与媒体成本仍由 Runtime 预留。

RuntimeProfile 的消息能力必须由调用方按实际 adapter 到 provider 的消费契约声明。Assembler 的多个 system 消息是共同构成上下文的有序片段；若下游把它们解释为完整快照并以后条替换前条，不能声明支持 multiple_system_messages。未声明该能力时 SDK 只合并相邻 system，并拒绝需跨 history 合并或显式要求多 system 的策略；不能靠任意拼接消除布局边界。最终投影必须保留这些片段的内容与顺序，模型成功回复不能反证能力声明正确。

startSession 只初始化新 Session：多开局须明确选择；Story 不接受独立 greeting_id。实际选定 locale 写入 Turn，opening 已进入 history，未提供问候返回 null；重放完整 Turn 不应再初始化或重复插开场。scene.opening 是场景上下文，不能冒充 assistant 问候。

作者 assembly_tests 支持 Creative 与 Preset，使用主动编写或明确保存的合成输入。root:self 避免循环语义摘要，源 raw bytes 与 session 原文必须复现。错误期望只吸收实际组装错误，不能掩盖缺依赖、版本或配置失败；观察结果不能自动更新期望。消息摘要包含附件内容身份而排除部署URL。

RuntimePreviewInput 是独立的严格合成文件，精确绑定 root、lock、artifact JSON、实际 preset/Profile/tokenizer 与完整 Story Turn；拒绝计划、正文、overlay、judgments 等额外字段。验证不把旧 Release 自动重绑新 dbld，不替用户补状态。Runtime 导出、Web 载入和保存作者测试分别需要明确操作。
