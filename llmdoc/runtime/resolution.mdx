# 统一产物与内容解析

buildCreation 从严格根身份与精确发布依赖快照生成完整 content/preset/prompt-module 产物，只有 content 带 IR。pin 摘要必须与完整规范化定义匹配；环、深度、实例数量和真实菱形版本冲突失败。依赖数据与可见性由调用方提供，纯解析器不授予读取权。

版本冲突按实际组装图与每个历史 derived_from 图分别检查，不能要求聚合分发闭包中每个 ref 永远只有一个版本。历史来源可保留旧版本、当前内容可升级同 ref；聚合锁保留精确 Release，fragment 索引还区分 digest，不能按 ref/Creation 键覆盖其中一个。历史来源参与许可、分级、授权和黑名单，但不再次注入上下文。

角色解析先验证作者模板图，再物化独立 cast 实例。词法 parent、reference children 与 cast ownership 是不同关系；cast_edges 和 introduced_by 保留实际归属。每个角色实例的 override、模板、头像与权限来源独立。公共 slot/speaker/ref 只能从声明实例的实际可达闭包解析：唯一实例可复用，多实例必须显式 cast，不得 first-match 或制造第二个角色。late 角色的 accepts 必须被目标 slot 完整接受。

CatalogIndex 从真实 reference 与 cast 边建立作用域，兄弟实例不能靠同名公共 ref 越界。fragments/groups/sources/sections 是定义与目录层，about 编译为带 from/ref/target 的导航链接；about 不意味着 include、激活或选择。完整性检查验证目标，运行展示还须经视角过滤，不能把 trusted index 直接给模型。

Story 的作者级 cast key 与编译后的 participant identity 分开。Story 纯求值按声明条件、三值判定、显式确认和场次进入更新状态；失败不推进，离开/重进、stop/continue、typed vars 和 clamp 遵循定义。自由输入不会自行确认目标；Jev 等外部判断只是可替换输入，不获得修改静态定义的权力。

Style 的最终放置顺序与候选选择/预算顺序分离。嵌套 Style 继承最近非 Style owner 的范围与顶层使用，再用内部 path 保留声明层级；replace 只在同 owner、层级与 scope 内比较，不误删其它 owner。root Style 的伪 scope 也保持显式身份。引用文本、Story 开场与 cast 文本模板使用同一编译管线，locale 和原始来源可追溯。

聚合 meta/assets/lock 表示所有随产物分发的内容，IR 是内容图；Preset、默认策略、模块、作者测试与历史来源不能因当前未选中而从生命周期消失。确定性重建必须用固定输入，不能解析 latest 或在旧产物缺配置时偷偷套当前默认。
