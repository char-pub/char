# LOOP

读取 `spec/goals/story-v1/PROGRESS.md`、VISION、DOR、DOD 与根 DECISIONS 后继续当前目标。用户最新指令优先；允许破坏性重构，无需维持旧产物字节。目标保持 active，直到全部 DOD 有最终证据。

按依赖推进：规范→身份/校验/纯求值→产物/上下文→发布与编辑器；独立调查可并行。失败时修复真实原因，不降低测试或删除需求。不因阶段序号停止已经可做的工作。

每轮记录源码路径、已运行检查、尚未完成项和下一步。没有验证不勾选 DOD。代码测试过不等于生产可用；人工 fixture 接受需要展示完整可审阅差异。

保留用户现有未提交文件，不撤销无关改动。Core 无 IO；不执行实际聊天/判定模型调用，不部署、不清理远端、不发布 npm、不强推。确需这些操作时准备好结果再依会话授权处理。

仅当所有 DOD 完成才报告 ALL DONE/完成目标。遇到外部阻塞先推进独立工作；若宿主中断，记录交接状态，不能把部分完成报告为全部完成。稳定 llmdoc 由 recorder 收尾更新。
